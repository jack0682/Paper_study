# 주장 장부

원고의 모든 정의, 가정, 보조정리, 정리, 수치 주장을 한 줄씩 등록합니다.
초록과 결론에는 상태가 `검증` 또는 `수치 근거`인 주장만 씁니다.

| ID | 종류 | 진술 (한 문장) | 의존 | 상태 | 근거 · 위치 | 담당 |
| --- | --- | --- | --- | --- | --- | --- |
| D1 | 정의 | | | | | |
| A1 | 가정 | | | | | |
| L1 | 보조정리 | | D1, A1 | 추측 | | |
| T1 | 정리 | | L1 | 추측 | | |

## 열 사용법

- **종류**: 정의, 가정, 보조정리, 정리, 따름정리, 수치 주장
- **의존**: 이 주장이 사용하는 다른 ID. 가정을 바꾸면 의존하는 주장을 모두 다시 확인합니다.
- **상태**
  - `추측`: 직관이나 예시만 있음
  - `스케치`: 증명 골격은 있으나 빈 단계가 있음
  - `검증`: 공저자 한 명이 전체 증명을 독립적으로 확인함
  - `수치 근거`: 재현 가능한 실험 기록(EXP-번호)이 있음
  - `반례`: 기각됨. 반례와 날짜를 근거 열에 남기고 행은 지우지 않습니다.
- **근거 · 위치**: 증명이 있는 `main.tex`의 절이나 라벨, 실험 기록 경로, 참고문헌 키
